# Contributing to OpenBoost

Thank you for your interest in improving OpenBoost!

## Getting Started
1. Fork the repository.
2. Clone your fork locally: `git clone https://github.com/your-username/OpenBoost.git`
3. Install dependencies: `npm install`
4. Run in dev mode: `npm start`

## How to Help
- Pick any open issue tagged `good first issue`.
- Test built executables on different Windows 10/11 environments and report bugs.
- Suggest new system tweaks or utility features via GitHub Discussions.
